1. 定義與接受

本服務條款（「本條款」）構成您與 Maknaa Group Sdn. Bhd.（「我們」）之間就使用我們的推論 API 服務（「本服務」）所達成之協議。存取或使用本服務即表示您確認已閱讀、理解並接受本條款。

如您代表某一組織接受本條款，您聲明並保證您有權拘束該組織，本條款對該組織具拘束力。

透過 OpenRouter 平台發起之呼叫另須遵守該平台之條款。就本服務本身而言，您與我們之間如發生衝突，以本條款為準。

本服務僅供商業及專業用途，不向消費者提供。您確認您將本服務用於商業目的，而非個人、家庭或家用目的，且您具有簽訂及履行本條款之完全行為能力。

2. 服務內容

我們透過相容於 OpenAI 的 API 提供模型推論，包括文字生成、工具呼叫及結構化輸出，具體如我們的 API 文件與模型目錄所述。

我們不擁有所服務的模型。模型權重歸其各自之權利人所有，我們依適用之授權提供推論。我們不保證任何特定模型之持續可用性；模型可能因上游授權變更、安全事件、效能原因或權利人要求而下線，我們將盡合理努力提前通知。

推論算力位於泰國，本服務由我們的馬來西亞實體營運。資料中心位置於我們 API 所提供之模型目錄中聲明。跨境安排見我們《隱私政策》第 12 節。

您必須妥善保管您的 API 金鑰，不得分享、轉售或於用戶端程式碼或公開程式碼庫中暴露。使用您金鑰進行之所有呼叫均視為您的行為，因此產生之費用與責任由您承擔。透過平台發起之呼叫，金鑰由平台管理及簽發；本節關於金鑰保管之義務不適用於此類呼叫，本條款其餘部分仍繼續適用。

如金鑰外洩或遭未經授權使用，您必須立即輪換金鑰並通知我們。於我們合理懷疑金鑰外洩或遭濫用時，我們得暫停相關金鑰。

  • 製作或散布惡意軟體、實施網路攻擊或未經授權存取系統；
  • 規避速率限制、配額或其他技術限制；
  • 將輸出用於對個人產生法律效力或類似重大影響之自動化決策，且未經人工覆核；
  • 超出我們發布或書面確認之配額、速率限制或合理使用門檻進行呼叫，或未經我們書面許可轉售推論算力；

違反本節可能導致流量限制、暫停或終止服務，且不予退款。涉嫌違法行為將報告主管機關，並依平台規則通知平台。

直接客戶：費用按用量計收，以美元計價，按月開立發票。我們按月開立發票，您須於發票日期後 30 天內付款。逾期款項按未付餘額每月 1.5% 計息，我們得暫停本服務。價格變更提前 30 天通知。
