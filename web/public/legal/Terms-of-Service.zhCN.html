1. 定义与接受

本服务条款（“本条款”）构成您与 Maknaa Group Sdn. Bhd.（“我们”）之间就使用我们的推理 API 服务（“本服务”）达成的协议。访问或使用本服务即表示您确认已阅读、理解并接受本条款。

如您代表某一组织接受本条款，您声明并保证您有权约束该组织，本条款对该组织具有约束力。

通过 OpenRouter 平台发起的调用还需遵守该平台的条款。就本服务本身而言，您与我们之间如发生冲突，以本条款为准。

本服务仅供商业和专业用途，不向消费者提供。您确认您将本服务用于商业目的，而非个人、家庭或家用目的，并且您具有签订和履行本条款的完全行为能力。

2. 服务内容

我们通过兼容 OpenAI 的 API 提供模型推理，包括文本生成、工具调用和结构化输出，具体如我们的 API 文档和模型目录所述。

我们不拥有所服务的模型。模型权重归其各自的权利人所有，我们依据适用的许可提供推理。我们不保证任何特定模型的持续可用性；模型可能因上游许可变更、安全事件、性能原因或权利人要求而下线，我们将尽合理努力提前通知。

推理算力位于泰国，本服务由我们的马来西亚实体运营。数据中心位置在我们的 API 所提供的模型目录中声明。跨境安排见我们《隐私政策》第 12 节。

3. 账户、密钥与安全

您必须妥善保管您的 API 密钥，不得共享、转售或在客户端代码或公开代码库中暴露密钥。使用您密钥进行的所有调用均视为您的行为，由此产生的费用和责任由您承担。通过平台发起的调用，密钥由平台管理和签发；本节关于密钥保管的义务不适用于此类调用，本条款其余部分继续适用。

如密钥泄露或被未经授权使用，您必须立即轮换密钥并通知我们。在我们合理怀疑密钥泄露或遭到滥用时，我们可暂停相关密钥。

4. 可接受使用

您不得使用本服务：

  • 违反马来西亚法律或您所在司法管辖区法律；
  • 侵犯他人的知识产权、隐私或其他权利；
  • 制作、传播或获取儿童性剥削或性虐待内容；
  • 制作或传播恶意软件、实施网络攻击或未经授权访问系统；
  • 规避速率限制、配额或其他技术限制；
  • 将输出用于对个人产生法律效力或类似重大影响的自动化决策，且未经人工复核；
  • 超出我们发布或书面确认的配额、速率限制或合理使用阈值进行调用，或未经我们书面许可转售推理算力；
  • 构建、部署或使用构成《欧盟人工智能法案》第 5 条所禁止行为的系统，包括社会评分、无差别抓取人脸图像、工作场所和教育中的情绪识别、利用脆弱性的操纵，以及在可公开进入的场所进行实时远程生物识别（法律特别授权的除外）；
  • 规避或试图规避模型安全措施或内容过滤器。

违反本节可能导致限流、暂停或终止服务，且不予退款。涉嫌违法行为将报告主管机关，并按平台规则通知平台。

如您在受监管行业使用本服务，您需自行承担本行业的合规义务。特别是，您不得将本服务用于《欧盟人工智能法案》附件三所列的高风险用途，除非您已自行完成该法案规定的上市前义务（包括风险管理系统、技术文档、人工监督措施和日志记录），且输出仍须由具备相应资质的人员进行实质性复核。我们仅作为模型推理的托管服务提供方提供算力和 API 访问；我们不参与您产品的设计、训练、部署或决策，亦非该法案或其他任何司法管辖区人工智能法规下的提供方。

5. 费用与支付

直接客户：费用按用量计收，以美元计价，按月开票。我们按月开具发票，您须在发票日期后 30 天内付款。逾期款项按未付余额每月 1.5% 计息，我们可暂停本服务。价格变更提前 30 天通知。

平台客户：通过 OpenRouter 平台发起的调用由平台按其规则收费，并由平台与我们结算。就此类调用，您与我们之间不存在直接支付关系，我们不负责平台的计费。

已支付的费用不予退还，法律要求或经我们书面明确同意的除外。

我们在状态页面公布实测可用性、首 token 时延和吞吐量。我们力求高可用性，但除非双方另行签署书面服务级别协议，可用性目标不构成可强制执行的承诺，也不产生任何服务补偿。

计划内维护提前 48 小时在状态页面公告。紧急安全维护可不经通知进行；我们将尽快恢复服务并在事后说明。

因不可抗力、上游网络或电力故障、第三方平台故障或您自身设备或连接导致的中断，不计入可用性数据，也不产生任何责任。

在您遵守本条款的前提下，您可将输出用于任何合法目的（包括商业目的），并可将输出整合到面向最终用户的产品或服务中。在法律允许的范围内，我们不对您收到的输出主张任何权利。输出可能并非唯一，并可能与现有作品相似；我们不保证输出不涉及第三方权利，使用风险由您自行评估并承担。

我们依据《数据政策》和《隐私政策》处理数据，两者均构成本条款的组成部分。提示词和输出不会被记录、持久化或用于训练；计费、技术和防滥用元数据在《数据政策》第 4 节所述范围和期限内留存。

您必须评估您的用例的合规性，尤其是在涉及个人数据、医疗保健、金融服务、法律服务或其他受监管行业时。本服务不构成专业建议，输出不应作为专业决策的唯一依据。

本服务按“现状”和“现有”提供。在法律允许的最大范围内，我们否认一切明示或默示的保证，包括适销性、特定用途适用性、不侵权、准确性、完整性和不间断运行。

我们不保证输出准确、完整、无偏见或不涉及第三方权利。模型输出具有概率性，相同的输入可能产生不同的结果。

在法律允许的最大范围内，任何一方均不对间接、附带、特殊、惩罚性或后果性损失负责，也不对利润、收入、商誉或数据损失负责，无论是否可预见。

我们因本条款项下全部索赔承担的累计责任确定如下：(a) 对于直接客户，为您在引起索赔的事件发生前 12 个月内就本服务实际支付的费用总额；(b) 对于平台客户，为平台就此类调用向我们结算的金额。无论何种情形，我们的累计责任不低于 10,000 美元。上述限制不适用于第 11 条的赔偿、故意不当行为或重大过失、死亡或人身伤害、欺诈，或法律不允许限制或排除的任何责任。

对于因您违反本条款、您非法使用本服务或您提交的内容侵犯第三方权利而产生的第三方索赔、罚款和费用（包括合理的律师费），您将对我们进行赔偿并使我们免受损害。

对于模型输出侵犯第三方知识产权，我们不提供任何赔偿或抗辩。您必须评估使用输出的风险，并自行获得该使用所需的第三方权利许可。如第三方就您使用输出向我们提出索赔，在法律允许的范围内我们不承担责任，但将合理配合您的抗辩。

12. 暂停与终止

在下列情形下，我们可立即暂停或终止本服务：您实质性违反本条款；付款逾期；涉嫌非法使用；法律或主管机关要求；或为保护本服务、其他客户或第三方所必需。

您可随时停止使用本服务。我们亦可提前 30 天通知终止。

终止后，第 1、3、5、7、8、9、10、11、14 和 15 条继续有效。

13. 条款变更

我们可修订本条款。修订内容将连同更新日期在此公布。对于重大变更，我们向直接客户提前 30 天发出电子邮件通知，并通过本页面和平台渠道通知经平台路由的客户。在生效日期后继续使用即构成接受；如不接受，您必须停止使用本服务并结清未付款项。

因本条款产生的争议应先经过 30 天的善意协商。协商不成的，除双方另有书面仲裁协议外，争议提交马来西亚吉隆坡有管辖权的法院专属管辖。
